SRT to Sound

Create synchronized Russian narration from finished SRT subtitles as M4A or WAV.

Release · 3.5.0 macOS 15+ · Apple Silicon
Download for macOS Source code Ruby · Swift User guide ↗

Before you startInstall Python 3.12 ARM64, FFmpeg, Silero packages and v5_5_ru.pt separately; they are not bundled. Not notarized by Apple.

What's inside

Installation, features, data flow and checks.

Installation

The steps from the installation guide, in Terminal.

$ brew install ffmpeg
$ brew install python@3.12
# PYTHON=/opt/homebrew/bin/python3.12 · APP_DATA=~/Library/Application Support/SRTtoSound
$ "$PYTHON" -m venv "$APP_DATA/.venv-silero-py312"
$ "$APP_DATA/.venv-silero-py312/bin/python" -m pip install -r "$REQUIREMENTS"
# Download the model v5_5_ru.pt manually, then compare its checksum:
$ shasum -a 256 "$APP_DATA/models/v5_5_ru.pt"
→ In the app: “Check setup”, then “Preview Voice”

Runs locally

Narration runs offline with the locally installed Silero model. The app downloads nothing while it generates speech.
