SRT to Sound

Erstellt synchronisierte russische Sprachausgabe aus fertigen SRT-Untertiteln als M4A oder WAV.

Release · 3.5.0 macOS 15+ · Apple Silicon
Herunterladen für macOS Quellcode Ruby · Swift Anleitung ↗

Vor dem StartPython 3.12 ARM64, FFmpeg, Silero-Pakete und Modell v5_5_ru.pt separat installieren; nicht im ZIP enthalten. Keine Apple-Notarisierung.

Was drin steckt

Installation, Funktionen, Datenverbindung und Prüfung.

Installation

Die Schritte aus der Installationsanleitung, im Terminal.

$ brew install ffmpeg
$ brew install python@3.12
# PYTHON=/opt/homebrew/bin/python3.12 · APP_DATA=~/Library/Application Support/SRTtoSound
$ "$PYTHON" -m venv "$APP_DATA/.venv-silero-py312"
$ "$APP_DATA/.venv-silero-py312/bin/python" -m pip install -r "$REQUIREMENTS"
# Modell v5_5_ru.pt manuell laden, danach die Prüfsumme vergleichen:
$ shasum -a 256 "$APP_DATA/models/v5_5_ru.pt"
→ In der App „Installation prüfen“, dann „Stimme anhören“

Läuft lokal

Die Vertonung läuft offline mit dem lokal installierten Silero-Modell. Während der Vertonung lädt die App nichts herunter.
