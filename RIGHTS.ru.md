# Права и разрешённое использование

Русская версия · [English](RIGHTS.en.md) · [Deutsch](RIGHTS.de.md)

Если владелец проекта не опубликовал отдельную лицензию, исходный код этого репозитория разрешено только просматривать. Разрешение копировать, изменять, адаптировать, распространять, передавать по сублицензии, продавать или использовать исходный код либо изменённые версии в коммерческих целях не предоставляется.

Владелец проекта разрешает частным лицам скачивать и запускать неизменённый опубликованный файл приложения для личного использования. Это не разрешает изменять, распространять, сублицензировать или использовать приложение в коммерческих целях. Условия сторонних компонентов, перечисленных в [уведомлении о сторонних компонентах](THIRD_PARTY.ru.md), действуют отдельно.

Условия GitHub могут разрешать просматривать или создавать форк публичного репозитория для функций платформы GitHub. Создание форка не даёт дополнительных прав на использование проекта за пределами этих функций.

Для этого проекта открытая лицензия не предоставляется. Чтобы получить дополнительные разрешения, обратитесь к владельцу проекта. Это уведомление не является юридической консультацией.
