# Сторонние компоненты и уведомления

Русская версия · [English](THIRD_PARTY.en.md) · [Deutsch](THIRD_PARTY.de.md)

Этот перечень относится к SRT to Sound. Он не является лицензией на проект и не заменяет условия сторонних авторов. В выпуск приложения не входят FFmpeg, пакеты Python, Silero и веса модели.

## Компоненты приложения и Apple

Исходный код использует системные фреймворки и средства командной строки Apple, включая AppKit, AVFoundation, Swift и Ruby. Они поставляются в составе Apple/macOS и не копируются проектом в экспорт исходников. Их использование регулируется применимыми условиями Apple.

Значки и скрипты — материалы проекта. Для них действуют только ограниченные разрешения из раздела [Права](RIGHTS.ru.md); общая лицензия с открытым исходным кодом не предоставляется.

## FFmpeg

Программа вызывает исполняемый файл, который пользователь устанавливает отдельно. Исполняемые файлы и библиотеки FFmpeg не входят в репозиторий или кандидат выпуска. FFmpeg сообщает, что большая часть его кода распространяется по LGPL 2.1 или новее, а включение необязательных компонентов GPL меняет применимую лицензию на GPL 2 или новее. Лицензия конкретной установленной сборки зависит от её конфигурации и компонентов. См. [юридические сведения FFmpeg](https://ffmpeg.org/legal.html) и [подробности лицензии FFmpeg](https://ffmpeg.org/doxygen/trunk/md_LICENSE.html).

## Silero и веса модели

Исходный код вызывает пакет Python Silero TTS и ожидает локально предоставленный файл модели `v5_5_ru.pt`; ни пакет, ни модель не включены. В upstream-коммите [`639eade`](https://github.com/snakers4/silero-models/tree/639eade0329fd0d99aa15dcfd204239a10c9be7e) README описывает русскую модель V5 как `v5_ru` с голосами `aidar`, `baya`, `kseniya`, `xenia` и `eugene`, а MIT указывает только для отдельных моделей `v5_cis_base`. Установленный загрузчик Silero 0.5.5 и проверенный артефакт используют локальное имя файла/идентификатор загрузчика `v5_5_ru`; закреплённые upstream README и индекс моделей прямо не документируют точное соответствие этого псевдонима данному файлу. У локально проверенного файла SHA-256 `50081637b602126ee06cb3bc8a744d25651d2da149ee8864b9a379bfdd934437`. Хэш подтверждает идентичность проверенных байтов, но сам по себе не устанавливает издателя или применимую лицензию.

В том же upstream-коммите есть расхождение в обозначении лицензии: значок README говорит «CC BY-NC 4.0», раздел лицензии называет общие условия «CC-NC-BY», а фактический закреплённый файл [`LICENSE`](https://github.com/snakers4/silero-models/blob/639eade0329fd0d99aa15dcfd204239a10c9be7e/LICENSE) содержит полный текст Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0). Этот проект принимает самый строгий подтверждённый режим: **только личное некоммерческое использование**. Не используйте модель Silero в коммерческих целях и не распространяйте веса через этот проект. Точное соответствие локально проверенного файла `v5_5_ru.pt` upstream-модели и её лицензии независимо не подтверждено. Это предосторожное ограничение проекта, а не юридический вывод и не разрешение указанного расхождения. Прежде чем полагаться на более широкие права, запросите письменное разъяснение или разрешение правообладателя.

Источники: [закреплённый README Silero](https://github.com/snakers4/silero-models/blob/639eade0329fd0d99aa15dcfd204239a10c9be7e/README.md), [закреплённый upstream LICENSE](https://github.com/snakers4/silero-models/blob/639eade0329fd0d99aa15dcfd204239a10c9be7e/LICENSE), [закреплённый индекс моделей](https://github.com/snakers4/silero-models/blob/639eade0329fd0d99aa15dcfd204239a10c9be7e/models.yml) и [официальная ссылка на файл модели](https://models.silero.ai/models/tts/ru/v5_5_ru.pt).

## Зависимости Python

PyTorch, SoundFile, NumPy и другие пакеты Python не включены. `requirements-silero.txt` фиксирует версии зависимостей, но не предоставляет полный набор лицензий на сторонние компоненты. У каждого пакета остаются собственная лицензия и уведомления; устанавливая дополнительное окружение, проверяйте метаданные полученных версий пакетов.

В изолированной QA-среде Python 3.12.14 ARM64 были установлены указанные ниже точные версии. Обозначения лицензий обобщают `License-Expression`, `License`, классификаторы и включённые файлы лицензий установленных дистрибутивов, когда эти сведения доступны. Это справочный перечень, а не юридическая консультация. Зависимости устанавливает пользователь; они не копируются в приложение или архив выпуска. Некоторые бинарные колёса, в частности NumPy, PyTorch и setuptools, могут содержать дополнительные сторонние компоненты с собственными уведомлениями; проверяйте их внутри установленного пакета.
