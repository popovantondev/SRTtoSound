SRT to Sound

Создаёт синхронизированную русскую озвучку из готовых SRT-субтитров в M4A или WAV.

Выпуск · 3.5.0 macOS 15+ · Apple Silicon
Скачать для macOS Исходный код Ruby · Swift Руководство ↗

Перед запускомОтдельно установите Python 3.12 ARM64, FFmpeg, пакеты Silero и модель v5_5_ru.pt. Они не входят в архив. Приложение не нотарифицировано Apple.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из инструкции по установке, в Терминале.

$ brew install ffmpeg
$ brew install python@3.12
# PYTHON=/opt/homebrew/bin/python3.12 · APP_DATA=~/Library/Application Support/SRTtoSound
$ "$PYTHON" -m venv "$APP_DATA/.venv-silero-py312"
$ "$APP_DATA/.venv-silero-py312/bin/python" -m pip install -r "$REQUIREMENTS"
# Модель v5_5_ru.pt скачать вручную, затем сверить контрольную сумму:
$ shasum -a 256 "$APP_DATA/models/v5_5_ru.pt"
→ В приложении: «Проверка установки», затем «Прослушать голос»

Работает локально

Озвучка идёт офлайн с локально установленной моделью Silero. Во время озвучки приложение ничего не загружает.

Проверено

  • Автоматические проверки в GitHub Actions (macOS 15): проверка синтаксиса и сборка приложения
  • Тесты Ruby и Swift запускаются локально через scripts/test.sh
  • Контрольные суммы SHA-256 (SHA256SUMS) в релизе
  • Версия 3.5.0 и журнал изменений
  • Короткие реальные озвучки проверены на одном Mac (по инструкции по установке)

Как это работает

  1. Открыть SRT
  2. Синтезировать речь
  3. Сохранить M4A / WAV

Первые шаги

Распакуйте приложение и сначала выполните установку зависимостей по руководству. Добавьте .ru.srt, выберите голос, формат и выходную папку.
