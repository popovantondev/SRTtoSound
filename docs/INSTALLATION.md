## Что входит и что требуется

Программа предназначена для macOS 15+ и Apple Silicon. В архиве приложения нет Python, PyTorch, Silero, весов модели или FFmpeg. Программа не устанавливает и не скачивает их при запуске или озвучке.

Для синтеза нужны отдельная среда **Python 3.12 ARM64**, зафиксированные зависимости из `requirements-silero.txt` и модель Silero `v5_5_ru.pt`. Для AAC/M4A и подгонки ритма нужен FFmpeg. Silero используется локально и поддерживает голоса Kseniya, Xenia, Baya, Aidar и Eugene. В рамках этого проекта использование Silero ограничено личными некоммерческими задачами; не используйте его для коммерческой работы. Модель в программу не включена. Точное соответствие файла модели upstream-лицензии независимо не подтверждено; подробности и ссылка на официальный источник — в [уведомлении о сторонних компонентах](../THIRD_PARTY.ru.md).

> Важно для этого кандидата 3.5.0: Python 3.12 ARM64, закреплённые пакеты, локальная модель и короткие реальные синтезы были проверены в изолированной QA-папке на одном Mac. Отдельный Mac и отдельная учётная запись не проверялись. Не переносите старое окружение Python 3.9 и не используйте папки SRT Озвучка 2.

## Папки новой программы

- Настройки и словарь: `~/Library/Application Support/SRTtoSound`
- Python: `~/Library/Application Support/SRTtoSound/.venv-silero-py312`
- Модель: `~/Library/Application Support/SRTtoSound/models/v5_5_ru.pt`
- Отчёты: `~/Library/Logs/SRTtoSound`
- Временные файлы: `~/Library/Caches/SRTtoSound`

Все эти пути отдельны от старой программы. Новая версия не импортирует старые настройки автоматически. Если нужен собственный словарь, скопируйте именно файл `произношение.txt` в новую папку Application Support; исходник сохраните.

## FFmpeg

Установите FFmpeg отдельно. Если Homebrew уже установлен, выполните:

```bash
brew install ffmpeg
ffmpeg -version
```

Проверьте, что FFmpeg доступен по стандартному пути `/opt/homebrew/bin/ffmpeg` или PATH. Программа должна выбирать тот же файл в проверке готовности и во время работы. FFmpeg нужен для AAC-LC/M4A и плавной подгонки длительности. M4A — формат по умолчанию; WAV остаётся альтернативой.

Если Homebrew ещё не установлен, используйте его официальную инструкцию на [brew.sh](https://brew.sh/) либо установите доверенную сборку FFmpeg для Apple silicon другим способом. Не запускайте команды установки с неофициальных сайтов.

## Silero — отдельная ручная установка

Сначала освободите достаточно места. PyTorch занимает много диска; не запускайте установку, если на целевом диске мало свободного места. Не устанавливайте Python или пакеты внутрь `.app`.

Установите версионированный интерпретатор Homebrew, не заменяя системный Python:

```bash
brew install python@3.12
/opt/homebrew/bin/python3.12 --version
/opt/homebrew/bin/python3.12 -c 'import platform; print(platform.machine())'
```

Ожидается Python 3.12.x и `arm64`. Если показано `x86_64`, остановитесь: не создавайте это окружение через Rosetta.

После подтверждения архитектуры откройте в Finder папку `SRT to Sound 3.5.0` внутри распакованного архива: в ней лежат приложение и `requirements-silero.txt`. В Terminal введите `cd ` (обязательно с пробелом после `cd`), перетащите эту папку из Finder в окно Terminal и нажмите Return. Теперь выполните команды ниже в том же окне:

```bash
PYTHON="/opt/homebrew/bin/python3.12"
REQUIREMENTS="$PWD/requirements-silero.txt"
APP_DATA="$HOME/Library/Application Support/SRTtoSound"
mkdir -p "$APP_DATA/models"
"$PYTHON" -m venv "$APP_DATA/.venv-silero-py312"
"$APP_DATA/.venv-silero-py312/bin/python" -m pip install -r "$REQUIREMENTS"
```

Не обновляйте pip отдельно: для проверяемой установки используются версии пакетов, указанные в этом файле.

Если вы принимаете указанное выше ограничение и условия поставщика модели, вручную скачайте Silero v5.5 Russian по адресу:

`https://models.silero.ai/models/tts/ru/v5_5_ru.pt`

Откройте Finder → «Переход» → «Перейти к папке…», вставьте `~/Library/Application Support/SRTtoSound/models` и нажмите Return. Перетащите скачанный файл в эту папку; имя должно быть ровно `v5_5_ru.pt`. Не переименовывайте другую версию модели под это имя. После скачивания запишите контрольную сумму локально:

```bash
shasum -a 256 "$HOME/Library/Application Support/SRTtoSound/models/v5_5_ru.pt"
```

Сравните результат с SHA-256 проверенной модели в `THIRD_PARTY.ru.md` из этого же выпуска. Если значения различаются, не запускайте озвучку и сообщите об этом.

Программа загружает эту локальную модель напрямую и не обращается к реестру моделей. Кнопка **«Проверка установки»** запускает найденный FFmpeg и проверяет наличие `atempo` и AAC-кодировщика; отдельно запускает Python и проверяет версию 3.12 и архитектуру `arm64`. Для модели она проверяет только наличие непустого файла — совместимость весов подтверждается реальным запуском голоса. При ошибке смотрите путь и техническое сообщение в окне проверки. Ничего не устанавливается и не скачивается.

Сначала нажмите **«Прослушать голос»** и проверьте Kseniya, затем попробуйте короткий синтетический `.ru.srt`.

## Первое использование

1. Откройте приложение и добавьте итоговый русский `.ru.srt` либо папку.
2. Выберите голос; по умолчанию используется Kseniya.
3. Оставьте AAC/M4A, если дорожка предназначена для MP4; WAV выберите только при необходимости.
4. Выберите сохранение рядом с SRT или в «Загрузки».
5. Запустите очередь. Сначала программа проверит всю очередь; при проблемах покажет их и предложит обработать только пригодные файлы либо вернуться к исправлению.
6. Проверьте созданный `.ru.m4a`/`.ru.wav` и отчёт. Чтобы открыть отчёт конкретной строки, выберите её в очереди и нажмите «Открыть отчёт»; без выбранного отчёта кнопка открывает общую папку. Исходный SRT приложение не изменяет.

## Обновление, возврат и безопасность

Перед обновлением закройте SRT to Sound. Скачивайте выпуск только со страницы Releases проекта и сверьте архив с опубликованной SHA-256-суммой. Распакуйте его и сохраните предыдущую программу, пока новая копия не пройдёт короткую проверку. В имени приложения указана версия: новую копию можно положить рядом с предыдущим выпуском SRT to Sound, не перезаписывая его. SRT Озвучка 2 остаётся отдельно.

Чтобы вернуться назад, закройте новую копию и откройте предыдущую версию SRT to Sound. Все версии 3.5.x используют общую папку данных `~/Library/Application Support/SRTtoSound`; возврат не восстановит настройки прошлой версии автоматически. Не удаляйте эту папку, а также отдельные папки журналов и кэша при обновлении. Удаление самого приложения не очищает его данные.

Приложение подписано локальной ad-hoc-подписью, но не нотарифицировано Apple. macOS может предупредить, что разработчик не проверен или приложение не проверено на вредоносный код. Apple рекомендует осторожность: ненотарифицированная программа не проходила такую проверку. Безопаснее не открывать приложение, происхождение которого вы не можете проверить. Если вы всё же решили продолжить, сначала сверьте точную SHA-256-сумму архива с официальным выпуском, затем используйте описанный Apple способ **«Открыть всё равно»** только для этого приложения в разделе «Конфиденциальность и безопасность» — не меняйте настройки защиты глобально. См. [рекомендации Apple по безопасности](https://support.apple.com/ru-ru/102445). Если контрольная сумма отличается, не открывайте приложение.

Перед использованием сверяйтесь с примечаниями именно к скачиваемому выпуску и запустите «Проверка установки» в приложении. Само наличие файлов Python и модели ещё не доказывает, что реальная озвучка готова.
