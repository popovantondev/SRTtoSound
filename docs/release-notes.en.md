# SRT to Sound · Release 3.5.0

## Changes

Version changes: https://github.com/popovantondev/SRTtoSound/commits/main/

## Compatibility

macOS 15+ · Apple Silicon

## Installation

Extract the app and complete dependency setup in the guide first. Add .ru.srt files and choose voice, format and output folder.

## Limitations

Install Python 3.12 ARM64, FFmpeg, Silero packages and v5_5_ru.pt separately; they are not bundled. Not notarized by Apple.
