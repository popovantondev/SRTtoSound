# Сборка и тестирование SRT to Sound

Инструкция на русском · [English](BUILD.en.md) · [Deutsch](BUILD.de.md) · [Установка](INSTALLATION.md)

![Интерфейс SRT to Sound на русском языке](screenshots/interface-ru.png)

Руководство относится к ветке версии 3.5 и не содержит персональных путей или данных.

## Требования

- macOS 15 или новее на Apple silicon;
- Xcode Command Line Tools (должны работать `xcrun --find swiftc` и `/usr/bin/ruby --version`);
- отдельно установленный FFmpeg для экспорта AAC и подгонки длительности.

Для сборки приложения и синтетических тестов Silero не нужен. Для проверки настоящего синтеза следуйте [инструкции по установке](INSTALLATION.md): там описана отдельная среда Python 3.12 ARM64 и ручное размещение модели.

## Проверка и сборка

From the repository root:

```sh
./scripts/test.sh
./scripts/build.sh
```

Скрипт тестирования сообщает фактические числа выполненных, неудачных, ошибочных и пропущенных тестов. Сборка создаёт новый `dist/SRT to Sound 3.5.0.app`, отказывается перезаписывать уже существующее приложение и не устанавливает и не запускает его. Необязательный аргумент задаёт другой каталог вывода.

## Упаковка выпуска

Упаковка выпуска — отдельный этап, требующий проверки. `PUBLIC_EXPORT_FILES.txt` — точный список исходных файлов для экспорта. Скрипт упаковки читает его из тега выпуска, отклоняет небезопасные и неотслеживаемые пути и включает только перечисленные файлы. Также требуется чистая рабочая копия, соответствующая тегу версии; скрипт проверяет приложение и встроенный манифест исходников и не перезаписывает каталог существующей версии. Не запускайте его для незавершённой проверки или выпуска, который владелец ещё не принял.

Приложение подписано локальной ad-hoc-подписью, но не нотарифицировано Apple. FFmpeg, пакеты Python, Silero и веса модели остаются отдельными зависимостями. Перед подготовкой публичного архива прочитайте [уведомление о сторонних компонентах](../THIRD_PARTY.ru.md) и [условия использования](../RIGHTS.ru.md).
