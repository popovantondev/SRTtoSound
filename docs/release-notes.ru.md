# SRT to Sound · Выпуск 3.5.0

## Изменения

Изменения версии: https://github.com/popovantondev/SRTtoSound/commits/main/

## Совместимость

macOS 15+ · Apple Silicon

## Установка

Распакуйте приложение и сначала выполните установку зависимостей по руководству. Добавьте .ru.srt, выберите голос, формат и выходную папку.

## Ограничения

Отдельно установите Python 3.12 ARM64, FFmpeg, пакеты Silero и модель v5_5_ru.pt. Они не входят в архив. Приложение не нотарифицировано Apple.
