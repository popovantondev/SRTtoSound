# SRT to Sound · Release 3.5.0

## Änderungen

Änderungen dieser Version: https://github.com/popovantondev/SRTtoSound/commits/main/

## Kompatibilität

macOS 15+ · Apple Silicon

## Installation

App entpacken und zuerst die Abhängigkeiten nach Anleitung einrichten. .ru.srt hinzufügen, Stimme, Format und Ausgabeordner wählen.

## Grenzen

Python 3.12 ARM64, FFmpeg, Silero-Pakete und Modell v5_5_ru.pt separat installieren; nicht im ZIP enthalten. Keine Apple-Notarisierung.
